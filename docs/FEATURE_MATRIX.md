# Feature matrix

| Domain | Implemented foundation |
|---|---|
| GPS & geofencing | Vehicle/trip domain, live tracking UI module, route-risk model |
| ECU diagnostics | OBD-II/CAN/J1939/UDS event domain and secure gateway ingestion |
| Predictive maintenance | Health/risk scoring, maintenance alerts, automatic work orders |
| Fuel | Level/efficiency domain, sudden stationary fuel-drop anomaly |
| EV | SOC, battery temperature and charging-oriented data model |
| Battery | 12V voltage alerts and battery state UI |
| Tyres & brakes | TPMS/brake-life thresholds and maintenance automation |
| Smart locks | Hood/trunk/fuel/battery lock workflows with guarded approvals |
| Cameras/ADAS | Camera event ingestion, review alerts, 360/dash/cabin architecture |
| Driver safety | Fatigue, distraction, health/wearables, identity/authorization UI domain |
| Cargo | Door/tamper, payload, cold-chain telemetry |
| Axle/load | Capacity/load risk in fleet risk engine |
| Road risk | Route-risk input and dynamic-dispatch module |
| Crash/SOS | Incident domain and automatic evidence-package initialization |
| Anti-theft | Tamper/unauthorized access and towing/movement capability model |
| ANPR/gates | Depot/environment automation module |
| Inspections | Pre/post-trip and visual-damage workflow domain |
| Digital twin | Lifecycle vehicle record and health/risk state |
| Cost analytics | Cost/km, utilization, carbon and residual-value capability model |
| Insurance/compliance | Policy, inspection, certification and claims capability model |
| Workshops/parts | Work order, parts/workshop matching capability model |
| AI copilot | Backend-safe copilot module boundary and natural-language workflows |
| Offline/satellite | Store-and-forward architecture and fallback adapter domain |
| Security/admin | RBAC rules, device trust, audit/control-plane architecture |
